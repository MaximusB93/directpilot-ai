## Состояние репозитория

Вся накопленная работа влита в `main` 03.09.2026. Открытых PR нет.

Что было: PR #137 (сверка доказательств в аудите, 93 коммита) был открыт с базой
`fix/final-audit-provider-timeout`, а не `main`, и оставался черновиком. Из-за
этого ни он, ни PR #136 не доходили до `main`, а `main` не содержал каталог
`frontend/` — проект `directpilot-ai-frontend` на Vercel настроен с
Root Directory = `frontend` и не собирался ни из `main`, ни из веток от него.

Цепочка закрыта одним PR #139: 94 коммита, 48 файлов. Один конфликт
(`scripts/preview-audit-smoke.mjs`, добавлен независимо в обеих ветках)
разрешён с сохранением обоих наборов возможностей. Проверки: `backend-ci`,
оба деплоя Vercel, 429 тестов — зелёные.

Побочный вывод: `backend-ci` настроен на `pull_request: branches: [main]`,
поэтому черновик с базой не-main не запускал CI ни разу. Все 93 коммита
впервые прошли автоматическую проверку только при вливании.

## Незакрытые вопросы

  на 6–8 модулей. Обязательно перед задачами 5 и 6. Отдельное ТЗ не написано.

  запросов из браузера, потому что у Vercel нет фонового процесса. Блокирует
  этап 3 (аудит по расписанию) и всё, что после.
- **Учёт расхода на ИИ и дневной лимит.** Один аудит — 88 011 токенов промпта.
  Ни лимитов, ни квот, ни учёта. Полдня работы, не запланировано.
- **Незаконченный переезд фронтенда.** Модули страниц вынесены, но не
  подключены: в каждом лежит записка `nextStep: подключить ... к ...Content`.
  Решить на этапе 0: доводить или откатывать.
- **Модель атрибуции** не передаётся в отчёты и не показывается пользователю.
  Все выводы по CPA содержат скрытое допущение.
