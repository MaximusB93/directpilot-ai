# Ограничения данных DirectPilot

Если не заполнен контекст бизнеса, выводы по нише, бренду, офферам, сезонности, конкурентам и посадочным страницам ограничены.

Если конверсионная метрика по выбранным целям отсутствует или некорректна, это неизвестное значение, а не ноль. Нельзя анализировать CPA по целям и CR; нужно проверить ID целей и повторить синхронизацию. При этом можно отдельно анализировать качество трафика по CTR, CPC, запросам, площадкам, устройствам, географии, аудиториям и частоте, не утверждая влияние на продажи.

Если источник достоверно вернул числовой 0, можно анализировать расход без конверсий только при достаточном объёме кликов и расхода. При малой выборке сначала расширь период до 60 и 90 дней.

Если нет поисковых запросов, нельзя качественно предложить минус-слова и оценить интент.

Если нет данных посадочных страниц, не утверждай, что проблема в лендинге. Можно только предложить проверить посадочную страницу как гипотезу.

Если есть только данные за вчера, не делай вывод о тренде. Для динамики нужны данные за несколько дней или недель.
